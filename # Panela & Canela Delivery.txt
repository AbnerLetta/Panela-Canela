# Panela & Canela Delivery

Aplicativo simples para pedidos via WhatsApp, feito em HTML, CSS e JavaScript.

## Estrutura
- index.html → página principal
- style.css → estilos
- script.js → lógica de interação
- assets/imagens → imagens dos produtos
- assets/icones → ícones extras
